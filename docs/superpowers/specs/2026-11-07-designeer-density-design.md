Finds > Dashboard returned Damir Sokolovsky's `Unslopping a vibecoded dashboard` (https://designeer.xyz/finds/heydamir-2115063463063998736). Implementation default under the existing redesign authorization: adapt the verified density/typography/surface principles to Coil's actual UI.
